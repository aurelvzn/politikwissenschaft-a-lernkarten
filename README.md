# Politikwissenschaft A – Lernkarten

## Themenstruktur

1. **Politik & Politikwissenschaft** – Politikbegriffe, Klimapolitik, wissenschaftliches Arbeiten und Forschungsprobleme.
2. **Macht** – Weber, Popitz, Arendt, Foucault und Lukes inklusive Anwendungsfälle.
3. **Ideologien** – Ideologiebegriffe, Liberalismus, Konservatismus, Sozialismus und Klimakrise.
4. **Woche 4 · Institutionen** – Institutionenbegriff, soziale und politische Institutionen, Neo-Institutionalismus und institutionelle Konfiguration.

## Nutzung

`index.html` im Browser öffnen. Alternativ im Ordner einen lokalen Webserver starten:

```bash
python3 -m http.server 8000
```

Dann `http://localhost:8000` aufrufen.

Lernmodus: Leertaste oder Klick dreht die Karte. Mit `1`, `2`, `3` bzw. den Buttons bewertest du sie. Fortschritt, Bewertungen sowie eigene Karten und Änderungen bleiben im Browser gespeichert.

## Quellenprinzip

Die Kartenbasis in `cards.js` enthält für jede Karte eine Quellenangabe zu Vorlesungsfolie oder bereitgestelltem Lektüreabschnitt. Es werden nur Inhalte aus `sources/` verwendet. Der bereitgestellte Auszug von Göhler (2011) wurde für Woche 4 visuell ausgewertet, weil er maschinell nicht auslesbar war.
